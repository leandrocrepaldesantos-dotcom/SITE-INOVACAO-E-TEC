# KuroEnergy 🌿⚡

**KuroEnergy — Monitore. Economize. Transforme.**

Projeto escolar desenvolvido para a disciplina de **Inovação Tecnológica e Empreendedorismo**, no curso Técnico em Desenvolvimento de Sistemas.

## Sobre o projeto

A KuroEnergy é uma proposta de empresa sustentável que busca ajudar pessoas a compreender e reduzir o consumo de energia em casa.

A ideia é monitorar o consumo, identificar equipamentos que gastam mais energia e apresentar dicas práticas para reduzir desperdícios e incentivar hábitos sustentáveis.

## Arquivos

- `index.html` — estrutura semântica e conteúdo da página.
- `style.css` — visual, responsividade e regras de acessibilidade.
- `script.js` — menu mobile e validação do formulário.
- `pitch-kuroenergy.png` — imagem utilizada na seção do pitch.

## Acessibilidade

O projeto foi estruturado com boas práticas de acessibilidade, incluindo:

- HTML semântico;
- navegação por teclado;
- indicador de foco visível;
- link "Pular para o conteúdo";
- textos alternativos nas imagens;
- `label` associado aos campos do formulário;
- mensagens de erro acessíveis;
- contraste visual elevado;
- suporte à preferência `prefers-reduced-motion`;
- layout responsivo para celular, tablet e computador.

## Segurança e privacidade

O formulário é apenas demonstrativo e **não envia dados para um servidor**.

Não utilize CPF, endereço residencial, telefone pessoal ou outros dados reais durante a apresentação.

> **Projeto Escolar Acadêmico sem Fins Lucrativos.**

## Como executar

### No VS Code

1. Baixe ou clone o repositório.
2. Mantenha os quatro arquivos principais e a imagem na mesma pasta.
3. Abra `index.html` no navegador.

### GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css`, `script.js`, `README.md` e `pitch-kuroenergy.png`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione a branch principal (`main`) e a pasta `/root`.
5. Salve e aguarde o GitHub Pages publicar o site.
